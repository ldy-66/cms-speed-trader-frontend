# 对冲台管理端前端复刻

这是根据提供的桌面端截图制作的静态 Web 原型，不连接真实交易、行情或账户接口。

直接用浏览器打开 `index.html` 即可，也可以在本目录启动任意静态文件服务器。

已实现的演示交互：

- 左侧导航选中态
- 客户订单筛选、重置、全选、撤选中、撤全部和分页
- 限价/市价两级选择；市价单按证券所属市场展示不同申报类型
- 市价类型说明、保护限价校验及市价委托明细展示
- 数量与价格步进、委托金额计算
- 买入/卖出校验并加入委托列表
- 极速OMS和普通OMS的批量下单导入预览
- 极速OMS和普通OMS的HighTouch确认、直接下单及拆单流程
- 双击各面板标题折叠或展开

所有订单及操作均为纯前端演示数据。
